This folder is a STATIC COPY of the portfolio (built HTML/JS).
It is NOT the git repo — there is no .git here.

To get the latest case studies and content:

1. Open Terminal in the REAL repo (after one-time clone), usually:
   cd ~/Ashish-Borchate-Portfolio

2. Run:
   git pull origin main
   npm install
   npm run export:desktop

3. Open the site:
   - Double-click "Open Portfolio.command" in THIS folder, or
   - From the repo: npm run dev -- --port 43123 → http://localhost:43123

Do NOT run git pull or npm run build inside Documents/cursor/Ashish-Borchate-Portfolio.

Clone once (Origin):
  origin repo clone ashish-borchate/Ashish-Borchate-Portfolio

See STATIC-PORTFOLIO.md in the repo for full steps.
